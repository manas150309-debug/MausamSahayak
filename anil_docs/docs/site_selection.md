# Site selection and permission

## Criteria (score 1-5 each)
1. Safe and supervised (campus, school, panchayat building, KVK farm) - protects against theft and vandalism
2. Real hazard: near a drain, canal, stream or river that has flooded before (ask locals, check state reports)
3. Open sky for the rain gauge (twice the obstacle height away from walls/trees) and for solar
4. Connectivity: Wi-Fi in range, or 4G signal strong enough for a GSM module later
5. Access: someone can visit weekly
6. Permission is realistic within 2 weeks

## Permission checklist
- [ ] Written permission from the owner / institution / panchayat (letter with node purpose, what is installed, who to call)
- [ ] Irrigation / water resources department consent if attaching anything to a canal, bridge or embankment
- [ ] Guide's signed letter to the site owner
- [ ] Safety: never work over water alone; nothing installed on a live road or public bridge without permission
- [ ] Emergency contact and a removal plan at project end

## Recommended for the 5-week window
- Node 1: campus, near a drain (safe, easy to demo, real rain)
- Node 2: a supervised site with a real drain/stream (KVK farm, school, or a friendly village)
- Optional Node 3: upstream of Node 2 on the same water course to test `upstream_node_id`
