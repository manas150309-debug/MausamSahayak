Core Engineering Design Principles

  • Fail-Safe Policy: Silent nodes or missing sensor values report as UNKNOWN, never false "GREEN / all clear".
  • Anti-Flapping Alert Guard: Escalations are instant; de-escalations require a 30-minute quiet hold.
  • Advisory Boundary: System only advises and points to state authorities (NDMA 1078, Police/Ambulance 112).
  • Offline Resilience: ESP32 buffers readings in local SPIFFS flash during Wi-Fi outages; backfilled on reconnect.
